[**Chit Tracker**](https://chit-tracker.vercel.app/) is an evolution of [Chit Calculator](@/projects/chit-calculator.md) and is a full-fledged responsive web application with account management that supports tracking multiple chits for each user. It uses [Supabase](https://supabase.io/) as backend and [ReactJS](https://reactjs.org/), [Tailwind CSS](https://v1.tailwindcss.com/) for frontend and [Vercel](https://vercel.com/) for frontend hosting.
